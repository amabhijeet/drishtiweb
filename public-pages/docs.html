How Drishti works

From capture to review

The mobile app captures a photograph with GPS metadata or a video segment paired with a GPX track. The processing server runs the pothole model and stores evidence and receipts. Reviewers inspect camera locations, compare reference points, and select media suitable for publication.

Reading a report

Model confidence describes a detection. GPS validation describes the supporting location evidence. Camera coordinates approximate where the road was observed. A reference match uses the configured tolerance and does not establish survey-grade accuracy.
